# Б. Стопы и В. Рейтинг — отчёт до выгрузки

**Фактическая выборка новой денежной/стоповой проверки: n=0 пригодных записей.** Ни стоп-анализ, ни source PnL не рассчитывались. Все цифры ниже сообщены владельцем; не выдаются за независимо проверенный финансовый результат. Модельные ALT_CLONE 119 лонгов не смешаны с настоящими LIVE-сделками.

## Б — заранее заданная методика

Для каждого настоящего fill: initial financial protectiveSL и исходное количество с timestamp, source/variant/code SHA; R и аварийный initial_stop отдельно. Шум — ATR14 по 14 завершённым **1m** свечам до entry, минимум предыдущая close для true range; при отсутствии данных ATR/SL ratio = NA, не подмена 1h. Скрипт выгружает имеющиеся исходники, индикаторы не выдумывает.

Ранние стопы: первичный N=15 минут, описательные 5 и 60 минут. Отсчёт от фактического entry fill до stop fill, не от сообщения. BE/защитный SL/trailing/time exit и частичное закрытие различать по событиям. Если идентичности нет — UNKNOWN.

«Выбило шумом»: только диагностическое достижение ORIGINAL TP1 в следующие 24 часа после фактического стопа; полный путь/покрытие, запрет подбора новых целей. Достижение цели потом не доказывает прибыль сделки без стопа: MAE/капитал/другие выходы могли ухудшить результат. Недостающий после-stop участок — censored, не «TP1 не достигнут».

Общие стопы: distinct trades минимум двух источников в фиксированном UTC-окне 5 минут; сопоставить BTC 5m return ≤−0,5% для LONG и ≥+0,5% для SHORT. Это временная ассоциация, не доказанная причина. Число событий/источников, экспозиция и совпадение R отдельно; одинаковая монета/повторные notifications не новые trades.

ALT_CLONE: нужны raw и managed пары по одному entry/initialR/fees/admission. Из difference нельзя арифметически приписать весь минус BE или трейлингу. Менеджерские правила взаимодействуют: сначала событийный журнал, затем фиксированные ablations с теми же входами, без подбора параметров, до PnL отдельный протокол. Exporter принимает сохранённые raw/managed ledgers и BE/trailing/partial events; из конечного snapshot их не восстанавливает.

## В — рейтинг источников

Заявлено: общий итог −13,81 USDT /102 сделки; PUMP_FADE n16 WR88%, +4,87R PF5,15; остальные около −28,3 USDT. До source-level cash reconciliation эти агрегаты нельзя складывать/пересчитывать как verified net: неизвестны полнота, даты, частичные exits и нормировка R. Новые WR, R/trade, PF, DD всех источников: **НЕ ПРОВЕРЕНО**. Скрипт сохраняет actual columns/source и не повторяет ошибку выбора close_profit_abs вместо realized_profit.

Предварительная категория по каждому из перечисленных источников: **СОБРАТЬ/СВЕРИТЬ ДАННЫЕ**, не автоматическое «оставить/понизить/выключить». Для PUMP_FADE — prospective проверка без увеличения риска; для ALT_CLONE — отделить модельный менеджерский эффект; для Олега/C10/MAIN — проверить stop/risk/partial cash; для RS1M — данных крайне мало. ALTCOIN_MGR n1 и OLEG_STYLE n3 исключены из сравнительных выводов и решений о качестве. Неизвестные остальные источники не объявлены нулевыми/прибыльными.

Цена ошибки раннего «оставить» — продолжение отрицательного expectancy/неизвестной корреляции; раннего «выключить» — потеря возможного преимущества; «снизить» не исправляет неверную бухгалтерию и не доказывает edge. Решение владельца, код допуска/риска не изменён. Количественная цена ошибки без пригодных данных не оценена.

Для доказательства PF: неизменный protocol до нового периода, actual receipt→intent→fill/no-fill и полный cash/funding/защитный SL, min lot/margin на 55USDT; ≥40 независимых закрытых — только предварительный screen, а не гарантия. Нужны положительные net-результаты в двух хронологических половинах и разных BTC режимах, PF≥1,3, стресс35/50bp, отсутствие зависимости от лучших дней/монет, кластерная неопределённость/контроль множественного отбора и независимый prospective период. Точное n для доказательства зависит от дисперсии и минимального эффекта, сейчас НЕ ОПРЕДЕЛЕНО. WR88% на n16 и один ENSO этого не заменяют.
