# Точный пакет для продолжения — только уже сохранённые выгрузки в приватный GitHub

Codex не подключается к Acer/Honor. Не нужны ключи, .env, Telegram sessions или запуск новых сервисов. Нужны исходные файлы за весь фактически сохранённый период с явными границами покрытия; для инцидента отдельно 20–21.11 и минимум 168h прогрева цен. Сырые приватные данные публиковать только в Crypto-Auto-Radar; car-research — обезличенный числовой ledger.

1. `freqtrade/user_data/shadow/pump_fade_signals.ndjson` и имеющиеся ротации — emitted feed, signal_ms/created_ms/уровни/model proof; producer state `pump_fade_S.json`, модельная версия/SHA, scan start/end/fetch/model/emit события. Для названия PUMP_FADE30 — точный StatePath, variant ID, рецепт и code SHA, не предположение, что это PUMP_FADE_S/top50.
2. `freqtrade/user_data/car_signals/signals.json` и `strategy_state.json`, доступные исторические снимки/ротации; ingest/strategy logs с UTC за 20–21.11, включая STALE_OR_FUTURE/filter/duplicate/WAIT/expiry/risk/slot/source/block отказы. Один текущий snapshot не заменяет все попытки и причины. Если quote/decision events никогда не логировались, прямо указать отсутствующие поля: прошлую цену решения невозможно восстановить точно.
3. Фактически установленный SHA или receipt/SHA256 `CarFastPathV1.py`, `ingest.py`, producer, report.py, стратегии guard и paper engine. Только безопасный extract релевантных параметров entry_tolerance_pct/entry_chase_frac/entry_better_frac/chase_after_tp1_sources, order type/pricing/timeouts, stop/TP/BE/admission gates. Не полный конфиг с ключами. Эти данные только читаются, менять настройки не требуется.
4. Из `tradesv3.fastpath.sqlite` — готовый согласованный read-only export PF entries/orders/fills/fees/funding, order_submit/request/ack/fill timestamps и signal ID; реальные protective SL/TP/BE и изменения. Нужны quantity, fee asset/value, realized_profit и close_profit_abs раздельно, funding cashflows, исходный financial risk. Сырые amounts/IDs не копировать в публичный репозиторий. Для схемы при необходимости достаточно готового результата PRAGMA table_info(trades), PRAGMA table_info(orders), PRAGMA table_info(trade_custom_data); никаких запросов, создающих ордера или меняющих БД.
5. Paper factory: готовый export `user_data/shadow/factory.sqlite` или фактического StatePath — opportunities/positions/events/rejects/NOFILL/data gaps, price cache и variants/code SHA. Не смешивать hourly shadow с 1m factory. Логи всех сигналов, а не только закрывшиеся победители.
6. Сохранённые native Bybit 1m и bid/ask/ticker quotes с exchange time/receive time в моменты решений и до terminal exit; BTC 1h для known r24 и 168h для известного peak. Отсутствующие ticks отметить явно. Не подменять Binance другим venue без отдельного протокола. Не просим многолетнюю повторную выгрузку.
7. Существующие egress probe/guard logs: UTC check source/result/duration/cache age/allowed-match/verdict, confirmed entries_blocked set/clear и ошибки Bybit, actual entry-deny events с signal ID, deployed guard code SHA. Нужен булевый результат сверки whitelist, не ключ и не изменение IP. Интервал 20.11 21:12–23:00 привести к UTC с указанной timezone. Изолировать unknown-IP и known-not-allowed. Сами предупреждения Telegram не заменяют block events.
8. Для строки «сигналов3/вошли1/цена уже…» — полный текст сообщения и message date/timezone, sender/code SHA, сохранённый обезличенный response Telegram отправки (без Bot API URL/токена). Для ENSO 21.11 — связанный signal/trade ID, entry/TP1/BE/close fills, комиссия и funding. Показанные 07:06/07:57/08:10 требуют timezone; итог +1,03$ пока только сообщение владельца.
9. Для оценки VPN — сохранённые endpoint request start/end/monotonic duration, proxy route/cache/result/retries/timeout и clock offset. Без них можно измерить только общий pipeline lag, не причинно приписать его Happ/VPN. Новые ping/Bybit probes в рамках этой задачи не запускаются.

До получения пригодного пакета пункты 2–6 отчёта остаются DATA_GAP/НЕ ПРОВЕРЕНО. Нельзя заменить их старыми 2 113 PF-исходами, 36 shadow-сделками без join или арифметикой 3−1.
