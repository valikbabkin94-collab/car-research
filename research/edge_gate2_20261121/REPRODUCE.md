# Воспроизведение проверки источников, без PnL

Ветка research/edge-gate2-20261121, папка research/edge_gate2_20261121. Python 3 standard library; для повторной сверки приватных GitHub SHA нужен уже авторизованный gh. Bybit-ключи, торговые SDK, .env и подключение к ноутбукам не нужны.

```bash
python research/edge_gate2_20261121/verify_evidence.py --github
```

Команда читает только закреплённые GitHub-источники: недельный журнал, текст экспортёра и дерево runtime-архива. Проверяет SHA256, число/схему записей и одинаковые blob SHA трёх архивных пар. Не выполняет экспортёр, не считает PnL, не обращается к биржам и не пишет сырые данные в публичную папку. Готовый вывод сохранён в VERIFICATION.json; повторять проверку для чтения отчёта не требуется.

Без флага --github проверяются только внутренние условия сохранённого FINDINGS.json, а не существование источников. Это не независимый торговый тест. Все 50 выбранных commit/tree SHA и флаги truncated доступны в FINDINGS.json; аудитор при необходимости может отдельно прочитать соответствующие Git trees через GitHub API GET. Дерево со скрытым другим именем файла не исключается одним совпадением имени: отсутствие источников ограничено описанным объёмом поиска.

READ_SOURCE_MANIFEST.json задаёт SHA256 конкретно прочитанных файлов. ARTIFACT_SHA256.json — контрольные суммы опубликованных артефактов этого этапа. Старые финансовые RESULTS.json, входы и код PR #1 не копировались и не перезаписывались. Исходные частные посты/журналы остаются в приватном репозитории.
