# Недостающие исходники для точного продолжения

Honor не использовался: задание разрешает только GitHub. Ниже поля, которые нужно выгрузить в эту исследовательскую ветку; исходные приватные тексты Telegram/сессии/ключи не нужны.

## IDEAS A/B/C — DATA_BLOCKED

Нужен исходный журнал **10882 A,5044 B,1648 C** из CODEX_IDEAS_20261110, не более поздние E2/E3 другой численности.

Для каждого исходного сигнала: immutable id, model A/B/C, native symbol/venue, decision_ms, exact entry_ms и entry reference price, side, исходный ATR14/SL distance, уровни TP/веса/BE/horizon, исходный split/purge/status, исходный hourly результат, идентификаторы random/unfiltered control и их точные входы. Нужны сохранённые part2_score.py/model.py/exits.py с SHA из CODE_MANIFEST либо точная версия эквивалентной модели. Параметры не восстанавливать подгонкой из агрегатов.

Если передаётся исходная цена без ATR/stop-distance, это недостаточно для того же исходного риска. Если передаются только свечи/OI/funding без исходных сигналов, это требует нового аудита реплики, а не пересчёта тех же входов.

## NIGHT фиксированный skip-filter — RECHECK_BLOCKED

Нужен PASSPORT_DATASET.csv из CODEX_NIGHT_20261110 либо три исходных таблицы из INPUT_MANIFEST с проверяемыми SHA:

* MANAGER_TRADES.csv:542 строки, sha256 d9b90c89e5fb1d33977676f6be40bd92de96219171e4b1020067b9dc78492251;
* MANAGER_TRADES_14_LOCAL.csv:1344 строки, sha256 c7ada2b4214d68661f99ad80a482def25f8a9d8b84f26a2bc05a0d206ca09c52;
* MANAGER_TRADES_LIVE_SOURCES_LOCAL.csv:642 строки, sha256 d2feb961c009a73767f001598f74773372de797ae44d60913d248f40d03bb538.

Минимально: dedup key/channel/id, publication_ms, symbol,side,cohort,entry_ms,half_original,MGR_R,RANDOM_R, исходные volatility_30d_pct и atr14_1h_pct, покрытие признаков, исходный split. Точное правило — **пропустить**, когда vol<=3.3569653056922872 И ATR<=0.9425751536145069. Пропуски признаков не равны нулю.

Старый DECISION_VALIDATION уже показывает именно этот фильтр: после него610 validation-сделок со средним−0.0107098334R. Это ранее исследованный результат, а не новая независимая проверка. Для повторной построчной проверки/случайного контроля/BH необходимы перечисленные строки.

## DUMP исходные Bybit-символы без Binance1m

Список конкретных gaps после минутного прогона — dump_shard0..3/ACTUAL_ROWS.jsonl.gz и SOURCE_ERRORS.json. Для них нужны исторические **Bybit1m** ровно на исходный час входа и72h, с immutable symbol/venue,timestamp,OHLC и SHA/источником. Альтернативная монета или новая цена входа не заменяет отсутствие исходного инструмента. Для точного ответа про исходный Bybit рынок также нужны минутные котировки Bybit по остальным1141 входам: результат Binance является межбиржевым прокси.

Файлы с публичным рынком/анонимизированным исследовательским журналом достаточно разместить через GitHub. Никаких LIVE выгрузок, ордерных ключей или Telegram-сессий.
