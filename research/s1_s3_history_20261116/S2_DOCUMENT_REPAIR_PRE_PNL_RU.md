# S2: исправление чтения документов до первого PnL Binance

Причина нулевой выборки установлена на сохранённых источниках, без просмотра цен/доходности S2: дерево rich-text Binance использует child (единственное число), а исходный парсер читал только children. Источники доступны и сохранены в RESULTS/ANNOUNCEMENT_SOURCES, это не отсутствие документов.

Извлекается текст child/children. Срок делистинга берётся только из блока «will close all positions and conduct an automatic settlement» до «The contract(s) will be delisted after...»; даты запрета открытия новых позиций не смешиваются со сроком расчёта. При нескольких сроках остаётся DATA_GAP, дата не угадывается по заголовку. Точное publishDate тела сверяется с releaseDate индекса.

Факты до PnL:
- PTBUSDT/MITOUSDT: публикация2026-10-21 09:30:01.882UTC; запрет новых обычных позиций с09:30UTC; первое5m open09:35 уже недоступно для обычного CAR. Оба входа REJECTED_NEW_POSITIONS_DISABLED. Привилегии отдельных market makers не предполагаются.
- PROMPTUSDT/PUMPBTCUSDT/1000000BOBUSDT: публикация2026-10-01 02:45:13.435UTC; расчёт2026-10-05 09:00UTC; выход2026-10-04 09:00UTC; запрет новых позиций2026-10-05 08:30UTC, после планового выхода. Три ценовых примера допустимы только условно по сегодняшнему тексту.

Старый нулевой результат и документы не удалять. Правила входа/8%SL/выхода/funding/fee неизменны; использовать кеш43874717889, не повторять S1/S3/полный сбор/API объявлений.

Ключевое ограничение: второго документа lastUpdateTime соответствует2026-10-01 03:39UTC, позже предполагаемого02:50 входа. Оригинальная редакция отсутствует. Поэтому causal_closed_n=0; три ретроспективных иллюстрации показываются отдельно как CURRENT_DOCUMENT_CONDITIONAL_PROXY, не как причинный OOS-бэктест или доказательство прибыли. Одна публикация с тремя монетами — не три независимых события.

## ПРОСТЫМИ СЛОВАМИ ДЛЯ ВЛАДЕЛЬЦА
Документы удалось разобрать. В двух монетах после новости уже запрещено открывать позицию; их нельзя считать реальными входами лишь потому, что свечи существуют. Остальные примеры покажут движение цены по сегодняшней редакции новости, но исходной редакции для строгого доказательства пока нет.
