# Уточнения до первого PnL хеджа

Исходный протокол 2b9ad3ae81d095441c2e6d0797e45d08bfddaa72 сохраняется. Результаты хеджа ещё не рассчитывались.

* Рынок и funding основного расчёта — Binance. Архив публичного Bybit funding обнаружен отдельно, но не подменяет Binance funding: это другая площадка. Для неизвестных выплат: ноль с отдельным стрессом ±0.01%/8ч; недостаток покрытия препятствует подтверждению. Реальный исторический mark из carry используется при наличии, иначе предшествующий close с отметкой proxy.
* Архив публичных типов инструментов Bybit исключает акции/ETF/сырьё/forex. Текущий Trading/status не фильтрует прошлую вселенную. Для отсутствующих в снимке инструментов нужна историческая spot-проверка. PIT-рейтинг — оборот, а не капитализация. Наличие реальной предшествующей Binance 5m-котировки — прокси доступности, а не доказательство исторической доступности Bybit.
* Только для корзины: SHIB1000→1000SHIB, PUMPFUN→PUMP, RAYDIUM→RAY, SKYAI1→SKYAI. Короткие входы и исходные DATA_GAP не исправляются этими соответствиями.
* Хедж исполняется после наблюдаемого close (close+1 сек); выплата funding на границе до открытия не причисляется к доходу. Для частичных закрытий в одной свече остаётся только реально открытая доля. Неизвестный внутрисвечной порядок не создаёт задним числом хедж.
* Если хедж заканчивается после границы H1, сделка исключается из выбора как PURGE_HEDGE_CROSS_SPLIT. Итог полного периода отдельно описательный, H1/H2 и последние40% с исходными границами; последние40% перекрываются с H2.
* Исходная подготовка путей run44171887648 сохранила PATHS.npz, INPUTS, SPLITS и PARENT_CONTROL_REPRODUCTION во всех4 artifacts; упала только сериализация итогового np.int64 в checkpoint. Восстановление использует эти файлы без повторения симуляций. Идентичность исходных масок/контрольного netR проверена assert до записи.
* В итогах доходность считается по закрытым сделкам (realized DD в R, не mark-to-market DD портфеля). Сигналы пересекаются, денежная проекция $5/R не является доходностью счёта55USDT.
