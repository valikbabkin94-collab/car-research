# Фабрика сценариев — фиксация до новых PnL

Пять кандидатов, по одному основному варианту; дополнительная модель комиссий S5 является парной чувствительностью, не независимым набором сделок. Пока нет новых результатов или доказанной прибыльности. Исполнение — только бумажное, установка отдельно Claude после разрешения владельца. Публично не публикуется код работающей фабрики или торгового бота.

## S1 PF_WIDE
Объединение текущего top200 USDT linear по24hturnover и всех USDT Trading stock/ETF, отмеченных самой биржей. PF_BASE ужеtop200, а modeltop50 — порог score. Для обычного top200 сохраняется неизменённый PF-модельный фильтр; для добавленного TradFi — исходный raw PF, как существующий PF_TRADFI. r24>=15%,откатот168hhigh>=3%,simpleRSI14<=65,24hrawcooldown;limit+1.3%,TTL8h,SL5.6%,TP2.1/4.2/6.3%,50/30/20,BEпослеTP1сследующей1m,max72h. Перекрывающиеся символы не дублируются.

## S5 PF_MAKER_EXIT
Те же самые сигналы/входы/выходы PF_BASE, связанные по base_id. Одновременно показываются taker0.055% на ногу и условные maker0.02% на entry/TP; SL/BE/TIME всегдаtaker. Это сравнение одинаковых исполнений, не новые независимые сделки. Рыночный или пересекающий спред лимит не является maker автоматически; OHLCV не доказывает очередь/post-only fill. Без подтверждённых maker fills вариант не продвигается. SL/TIME slippage прежний, funding одинаковый. Исторически можно пересчитать расходы сохранённых исследовательских сделок, не заявляя новые исполнения.

## S3 FUND_SQUEEZE
Текущий top200. Наблюдаемый публичный ticker funding<=−0.001 в пересчёте на8h по фактическому fundingInterval биржи; неизвестный интервал — отказ. Сигнал: минимум последних6 закрытыхH1 не ниже минимума предыдущих18 закрытыхH1, то есть24hминимум не обновлялся6h. Все24H1непрерывны. LONG по первой доступной1mпосле фактического наблюдения, стоп24hmin*(1−1e−8); еслиentry<=stop — отказ до qty. TP1/2/3R от ценового риска,50/30/20,безBE,max48h. Одинсигнал/символ/24h. Исторический опубликованный settled funding не равен предсказанному tickerfunding: допустим только явно помеченный отдельный proxy, а основной исторический тест без ticker-снимков DATA_BLOCKED. Платежи funding считаются по настоящим опубликованным событиям, не по прогнозу.

## S2 DELIST_SHORT
Только точный timestamp публикации официального анонса Bybit о USDT perpetual delisting. Требуются официальныйURL, точное время и одна однозначная дата прекращения торговли сUTC; исключаются temporary suspension/migration. Publication, first_seen, observed и scheduled_delist сохраняются отдельно. SHORT по первой доступной1mпосле наблюдения, только если она ещё внутри первого часа после публикации. Deadline=delist−24h, не announcement endDate; если deadline уже близко — отказ. SL8%,безTP/BE;выход по известному deadline. Статус instruments-info без анонса не восстанавливает публикацию задним числом. Task207 имел другие дневные правила и funding24bps: они не переносятся в новый S2. Нет архива точных анонсов/их первых версий — исторический тест DATA_BLOCKED.

## Проверки и продвижение
Каждую неделю, понедельникUTC: все варианты, n/WR/PF/R/$5risk/DD/средняя длительность, rejected/nofill/dataunknown. Обязателен отдельный суммарный период с общей датой начала для нового варианта и BASE. Продвижение:>=30закрытых,PF>=1.3,строго лучшеBASE на том же периоде,net>0,maxsingleprofit/net<=30%;полныерасходы и отсутствие открытых/непокрытых исходов. Только предложение владельцу, никакого автоматического LIVE.

Для исторических проверок: заранее разделённые H1/H2/TAIL40,1000seed20261116matchedконтролей, комиссии0.055%/0.02% на фактическую ногу, adverse market slippage5bps, реальное funding, консервативный порядок SLfirst/noTPfillbar/nextbarBE. Старые эксперименты не повторяются: G3h98сделок+9.0166R/PF1.2287 переносится только как ранее выполненная хрупкая диагностика. Без причинных объявлений/тикеров/BybitPIT данные не заменяются удобным прокси без маркировки. Новых параметров после PnL не выбирать.
