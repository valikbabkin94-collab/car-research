# car-research

Публичный репозиторий **только для исследований** CAR (бэктесты, сбор открытых рыночных данных, отчёты).

Правила:
- Здесь НЕТ кода торгового бота, стратегий LIVE, конфигов, ключей, токенов, chat_id, IP и адресов VPN. Никогда не добавлять.
- Данные — только публичные (Binance data.binance.vision, публичные GET Bybit/Deribit).
- Протокол исследования коммитится ДО PnL; отрицательные результаты сохраняются.
- Рабочий (приватный) репозиторий бота: отдельно, сюда не копируется.
